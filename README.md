# Нейронет — десктопный анализ сессии

Локальное приложение с одним фронтальным видео, сигналами BioRadio и стенограммой на общей временной шкале. Интерфейс сделан на PySide6, видео воспроизводится через Qt Multimedia. HTTP-сервер и браузер для работы не нужны.

## Установка и запуск

```bash
cd /Users/dumbcl/neuronet/neuronet_lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m neuronet_lab.desktop
```

На macOS после установки можно также запустить приложение двойным щелчком по `Запустить Нейронет.command`.

На Windows окружение активируется командой `.venv\Scripts\activate`. Для базового просмотра, импорта CSV и ручной стенограммы достаточно `pip install -r requirements-core.txt`. Дополнения для анализа видео и расшифровки речи ставятся через `requirements-video.txt` и `requirements-audio.txt`.

Qt Multimedia поддерживает воспроизведение через системные кодеки и свой мультимедийный движок. Если конкретное видео не открылось, попробуйте MP4/H.264. Исходное видео копируется в `data/sessions/<id>/`; CSV разбирается в массивы NumPy внутри той же папки. Данные не отправляются в сеть. При первом запуске **автоматической** расшифровки faster-whisper может скачать модель `small` в локальный кеш.

## Работа в приложении

1. Создайте сессию, добавьте фронтальное видео и экспорт BioRadio CSV. Импорт большого CSV выполняется в фоновом потоке.
2. Укажите для каждого файла метки начала покоя, начала и конца разговора и конца записи. Время вводится от начала соответствующего файла: секунды или `мм:сс`. Для видео можно взять время из текущего положения плеера. Совпадающие метки выравнивают записи кусочно-линейно; одна метка задаёт постоянный сдвиг.
3. Управление воспроизведением находится над видео: пуск/пауза, переход на ±5 секунд и ползунок времени. Область под видео прокручивается от меток синхронизации до отдельных увеличенных графиков BioRadio. После остановки или перемещения курсора рядом с плеером показываются текущие признаки и краткие показания BioRadio.
4. Во вкладке «Стенограмма» добавьте реплики вручную или запустите автоматическую расшифровку. Укажите говорящего как «Интервьюер» или «Респондент», проверьте текст и сохраните.
5. Во вкладке «Интервал» задайте начало и конец, затем рассчитайте показатели ЭКГ, ФПГ, дыхания, GSR, rPPG, позы и речи. Во вкладке «Разметка» можно сохранить название фрагмента и экспертную метку «база / правда / ложь».

Импорт проверен на обычном экспорте BioRadio с частотой 500 Гц и на предоставленном `fokin.csv` с частотой 1000 Гц, где десятичная запятая одновременно служит разделителем CSV.

## Границы результата

- ВСР (SDNN, RMSSD, LF/HF) рассчитывается для интервалов от 120 секунд. Пики и артефакты требуют проверки на исходном сигнале.
- Видеоанализ использует OpenCV; при наличии MediaPipe включается модель позы из `models/`. При потере лица или видимых частей тела соответствующие значения остаются пустыми.
- Автоматическое разделение двух голосов приблизительное. Метки и стенограмму нужно проверить вручную.
- Для автоматической расшифровки используется локальная модель faster-whisper; звук декодируется напрямую через PyAV, в том числе с текущими версиями PyAV, где отсутствует параметр `metadata_errors`.
- **Вероятность лжи не вычисляется:** для неё необходимы размеченная выборка, обучение и отдельная проверка модели. Экспертная метка интервала не является прогнозом.

## Структура

- `neuronet_lab/desktop.py` — нативное окно, плеер, графики и редакторы.
- `neuronet_lab/session.py` — хранение сессий и синхронизация файлов.
- `neuronet_lab/bioradio.py` — потоковый импорт и выборка CSV.
- `neuronet_lab/analytics.py` — показатели интервала.
- `neuronet_lab/media.py` — лицо, поза, rPPG и речь.
- `models/haarcascade_frontalface_default.xml` — детектор лица из [официального репозитория OpenCV](https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml), используемый при отсутствии XML в пакете OpenCV.
- `tests/` — проверки импорта, синхронизации и окна приложения.

Проверка: `python -m unittest discover -s tests -v`.
