# Нейронет — десктопный анализ сессии

Локальное приложение с одним фронтальным видео, сигналами BioRadio и стенограммой на общей временной шкале. Интерфейс сделан на PySide6, видео воспроизводится через Qt Multimedia. HTTP-сервер и браузер для работы не нужны.

## Установка и запуск

```bash
cd /Users/dumbcl/neuronet/neuronet_lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m neuronet_lab.desktop
```

На macOS после установки можно также запустить приложение двойным щелчком по `Запустить Нейронет.command`.

На Windows окружение активируется командой `.venv\Scripts\activate`. Для базового просмотра, импорта CSV и ручной стенограммы достаточно `pip install -r requirements-core.txt`. Дополнения для анализа видео и расшифровки речи ставятся через `requirements-video.txt` и `requirements-audio.txt`.

Qt Multimedia поддерживает воспроизведение через системные кодеки и свой мультимедийный движок. Если конкретное видео не открылось, попробуйте MP4/H.264. Исходное видео копируется в `data/sessions/<id>/`; CSV разбирается в массивы NumPy внутри той же папки. Данные не отправляются в сеть. При первом запуске **автоматической** расшифровки faster-whisper может скачать модель `small` в локальный кеш.

## Работа в приложении

1. Создайте сессию, добавьте фронтальное видео и экспорт BioRadio CSV. Импорт большого CSV выполняется в фоновом потоке.
2. Укажите для каждого файла метки начала покоя, начала и конца разговора и конца записи. Время вводится от начала соответствующего файла: секунды или `мм:сс`. Для видео можно взять время из текущего положения плеера. Совпадающие метки выравнивают записи кусочно-линейно; одна метка задаёт постоянный сдвиг.
3. Управление воспроизведением находится над видео: пуск/пауза, переход на ±5 секунд и ползунок времени. Область под видео прокручивается от меток синхронизации до отдельных увеличенных графиков BioRadio. После остановки или перемещения курсора рядом с плеером показываются текущие признаки и краткие показания BioRadio.
4. Во вкладке «Стенограмма» добавьте реплики вручную или запустите автоматическую расшифровку. Укажите говорящего как «Интервьюер» или «Респондент», проверьте текст и сохраните.
5. Во вкладке «Интервал» задайте начало и конец, затем рассчитайте показатели ЭКГ, ФПГ, дыхания, GSR, rPPG, позы и речи. Во вкладке «Разметка» можно сохранить название фрагмента и экспертную метку «база / правда / ложь».

Импорт поддерживает обычный CSV, разделитель `;`, десятичные запятые в кавычках и предоставленный вариант BioRadio, где десятичная запятая одновременно служит разделителем CSV. Структура проверяется отдельно для каждой строки, в том числе когда GSR или другой аналоговый канал записан целым числом. Неоднозначные строки остаются пропусками с исходным временем; их число и пропуски по каналам записываются в `signal_meta.json`. Для восстановления неэкранированных запятых используются целочисленные поля HR/SpO₂/Event и предел аналоговых значений ±2³¹. Обычного CSV и значений в кавычках эти ограничения не касаются; экспорт с `;` или кавычками предпочтительнее.

Для старой сессии повторно импортируйте исходный CSV. Во вкладке «Стенограмма» кнопка **«Пересчитать акустику по видео»** обновляет измерения на всей длине существующих реплик, сохраняя тексты, говорящих, синхронизацию и разметку. Повторная автоматическая расшифровка для этого не требуется. Покадровые акустические показатели сохраняются отдельно в `audio_features.npz`.

### Определения показателей

- Ответ определяется как последовательность реплик респондента до смены говорящего. Задержка считается от конца предшествующей последовательности реплик интервьюера до начала ответа, включая контекст вне выбранного интервала. Отрицательная задержка означает наложение речи. Это приближение: короткая вставка интервьюера делит ответ.
- Полная длительность ответа включает паузы между его репликами. Темп в выбранном интервале делит количество слов на попавшую в интервал длительность ответов, включая эти паузы. Слоги оцениваются по числу гласных. При частичном пересечении реплики слова считаются по временным меткам слов; если их нет, темп недоступен. Редактирование текста или границ сбрасывает устаревшие временные метки слов.
- RMS и спектральный центр считаются по всей реплике; для произвольного интервала используются окна 50 мс с шагом 20 мс, полностью попавшие в речь респондента. F0 — медиана кадров с достаточной энергией и периодичностью в диапазоне 70–400 Гц; отдельно показывается IQR. На тишине и непериодическом шуме F0 отсутствует. Это оценка основного тона, требующая проверки на реальной речи.
- Основная ЧСС rPPG интервала включает только оценки, **всё окно расчёта которых находится внутри интервала**. «rPPG с учётом предыстории» показывает контекстные оценки, использующие до 12 секунд до текущего кадра. `rppg_coverage` — доля временных точек с подходящим окном, а не точность метода. У старого кеша границы окон восстанавливаются по периоду обнаружения лица.
- Скорость смещения рамки лица выражается в ширинах лица в секунду и включает дрожание детектора. Новая видеообработка учитывает соотношение сторон кадра для наклона корпуса и движений конечностей; единица скорости конечностей — высоты изображения в секунду. Для старого кеша интерфейс предлагает повторить анализ видео. Наклон корпуса остаётся двумерной оценкой.
- Вычисления сохраняют числовую точность; округление выполняется при отображении.

## Границы результата

- ВСР (SDNN, RMSSD, LF/HF) рассчитывается от 120 секунд при достаточном числе пригодных интервалов. Детектор не соединяет участки через пропуски; скрининг RR отбрасывает интервалы вне 0,3–2 с и отклонения более 25% от локальной медианы. Для ВСР допускается не более 5% отброшенных интервалов; RMSSD использует только соседние пригодные интервалы. Для спектра сохраняются исходные времена ударов, единичные исключения интерполируются; большие разрывы блокируют расчёт. Эти эвристики не заменяют проверку пиков на исходном сигнале.
- Спектр RR — односторонняя периодограмма с окном Hann после интерполяции RR в миллисекундах на сетку 4 Гц. Плотность выражена в мс²/Гц, LF (0,04–0,15 Гц) и HF (0,15–0,4 Гц) — в мс². `total_power` содержит сумму LF+HF с явной границей 0,04–0,4 Гц. ULF/VLF остаются недоступны: окна лабораторной недостаточны для надёжной оценки этих диапазонов. Ограничения длительности описаны в [рекомендациях SPR, 2024](https://doi.org/10.1111/psyp.14604).
- Видеоанализ использует OpenCV; при наличии MediaPipe включается модель позы из `models/`. При потере лица или видимых частей тела соответствующие значения остаются пустыми.
- Автоматическое разделение двух голосов приблизительное. Метки и стенограмму нужно проверить вручную.
- Для автоматической расшифровки используется локальная модель faster-whisper; звук декодируется напрямую через PyAV, в том числе с текущими версиями PyAV, где отсутствует параметр `metadata_errors`.
- **Вероятность лжи не вычисляется:** для неё необходимы размеченная выборка, обучение и отдельная проверка модели. Экспертная метка интервала не является прогнозом.

## Структура

- `neuronet_lab/desktop.py` — нативное окно, плеер, графики и редакторы.
- `neuronet_lab/session.py` — хранение сессий и синхронизация файлов.
- `neuronet_lab/bioradio.py` — потоковый импорт и выборка CSV.
- `neuronet_lab/analytics.py` — показатели интервала.
- `neuronet_lab/media.py` — лицо, поза, rPPG и речь.
- `models/haarcascade_frontalface_default.xml` — детектор лица из [официального репозитория OpenCV](https://github.com/opencv/opencv/blob/master/data/haarcascades/haarcascade_frontalface_default.xml), используемый при отсутствии XML в пакете OpenCV.
- `tests/` — проверки импорта, синхронизации и окна приложения.

Проверка: `python -m unittest discover -s tests -v`.
