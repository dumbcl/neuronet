# Проверка сессий — 21 октября 2026

## Сохранение данных для датасета

Основная единица будущей строки датасета — полный ответ респондента. В каждой сессии сохранён плоский список `answers` с границами, классом, идентификатором участника, ссылками на реплики и вопрос, внутренними паузами и исходными экспертными интервалами. Это позволяет позже получить `participant_id, answer_id, start, end, target, признаки…` без повторной ручной разметки.

Молчание в разметке просмотра остаётся «базой». Внутренняя пауза связана с ответом через `answer_id`, поэтому не разрывает полный ответ и не меняет его класс. Длительность ответа и темп речи учитывают внутренние паузы; пауза до начала ответа относится к задержке ответа. Для будущей выгрузки нужно брать `answers`, а не отдельные строки `annotations`.

Исходные классы сохранены отдельно в `annotation_sources`; связь с ними позволяет проверить происхождение каждого таргета. Классы не определялись по смыслу автоматически. Исключение — вступительные и заключительные «База-речь» Дуброва: по прямому уточнению пользователя они переведены в правдивые ответы; исходная метка и основание изменения сохранены.

Использованы контекст стенограммы, исходные экспертные интервалы, локальная повторная ASR отдельных спорных мест с временными метками и консервативная проверка тихих участков по энергии аудио. Это не сплошная ручная прослушка всех записей. Неясные слова не заменялись догадками. Полная длительность ответа в любом случае включает время между его началом и концом.

## BioRadio

Импорт исправлен для пустого последнего поля Event и служебных значений HeartRate=511 / SpO₂=127. Некорректные показания маскируются только в соответствующем канале, остальные измерения и исходное время сохраняются.

- **Комаров:** повторный импорт 1 111 590 отсчётов при 1000 Гц. Вместо 18 266 целиком потерянных строк из-за недопустимых HR/SpO₂ осталось 148 действительно неоднозначных строк. В HR и SpO₂ отдельно скрыты по 18 266 служебных значений. Эти показания не восстанавливались интерполяцией.
- **Яхяев:** повторный импорт 1 616 040 отсчётов при 1000 Гц. Осталось 99 неоднозначных строк; пустой Event больше не мешает разбору других каналов.
- **Маргарян и Дубров:** ранее восстановленные массивы сохранены; 250 Гц — частота из временной шкалы их файлов. Постоянный GSR=100000 не содержит пригодной динамики: исходные числа сохранены, аналитика возвращает отсутствие показателя вместо среднего 100000.

Якоря синхронизации не перемещались. У Фокина сигнал опережает видео на 14 секунд, поэтому времени видео соответствует время BioRadio +14 с; у Комарова +32 с, у Яхяева +94 с. У Маргаряна сохранено существующее кусочно-линейное выравнивание. У Комарова остаётся ранее отмеченная неопределённость около 2 секунд. **У Дуброва метки синхронизации сигнала отсутствуют**: его физиологические признаки нельзя считать проверенными для соответствующих ответов до выравнивания. Приложение сообщает об этом при расчёте.

Границы тихих базовых периодов для просмотра уточнены по отсутствию речи, без изменения якорей синхронизации. Акустика четырёх новых сессий пересчитана после изменения границ реплик с сохранением текстов, классов и синхронизации.
